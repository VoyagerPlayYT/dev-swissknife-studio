Универсальный комбайн разработчика «всё в одном» для ежедневной инженерной работы: живой тестер регулярных выражений (Regex) с группировкой и подсветкой совпадений, двусторонний конвертер JSON <-> YAML с валидатором синтаксиса, криптографическая лаборатория (генерация MD5, SHA-1, SHA-256, парсинг JWT-токенов, криптостойкие пароли с оценкой энтропии) и живая песочница SQLite для выполнения произвольных SQL-запросов с замером времени в миллисекундах.

## Состав студии

1. **Regex Lab & Group Inspector:**
   - Мгновенная компиляция выражений на сервере (библиотека `re`) с флагами `i` (Ignore Case), `m` (Multiline), `s` (Dot All).
   - Табличный вывод полного совпадения, смещений `[start:end]` и всех захваченных групп `$1`, `$2`.
2. **JSON & YAML Studio:**
   - Двунаправленная конвертация между форматами через `json` и `PyYAML`.
   - Кнопки форматирования (Prettify) и сжатия (Minify).
3. **Crypto & JWT Inspector:**
   - Мгновенный расчет хешей `MD5`, `SHA-1`, `SHA-256`, `Base64`.
   - Декодер структуры JWT-токенов: изолированный разбор `Header`, `Payload` (Claims) и контрольной подписи `Signature`.
   - Генератор криптостойких паролей на `window.crypto.getRandomValues` с расчетом битовой энтропии Шеннона.
4. **SQLite Sandbox Engine:**
   - Реальное исполнение SQL-запросов на серверной базе SQLite.
   - Предустановленные связанные таблицы `developers`, `microservices`, `telemetry_events`.
   - Сетка результатов с названиями колонок, количеством строк и замером скорости выполнения (`ms`).

## Зачем этому проекту нужен выделенный домашний сервер 24/7 (HP ProLiant DL360 Gen9)

1. **Безопасная локальная песочница без отправки секретов наружу:** Большинство разработчиков пользуются онлайн-сервисами (regex101, jwt.io, base64decode), рискуя слить приватные токены, ключи и конфиги на чужие серверы. Развертывание Swissknife Studio на домашнем сервере HP ProLiant DL360 Gen9 гарантирует, что конфиденциальные данные никогда не покинут изолированную домашнюю сеть.
2. **Безопасное тестирование SQL-миграций:** Выделенная память сервера позволяет тестировать тяжелые аналитические запросы и сложные объединения таблиц без риска уронить локальную рабочую станцию.
3. **Круглосуточная доступность для всех машин разработчика:** Инструмент мгновенно открывается в браузере любого устройства в домашней сети по постоянному адресу.
4. **Высокая отказоустойчивость:** Серверное исполнение на базе FastAPI гарантирует мгновенный отклик даже при валидации мегабайтных JSON и YAML файлов.

## Запуск в 1 клик

```cmd
start.bat
```
Скрипт установит `fastapi`, `pyyaml`, `uvicorn` и откроет Dev Swissknife Studio на `http://localhost:8016`.
